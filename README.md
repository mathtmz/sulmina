# Sulmina

Repositório unificado com o site original da Sulmina e o tema personalizado da Nuvemshop.

## Pastas

- [`site/`](site/): site estático original, mantido como referência de conteúdo e identidade visual.
- [`nuvemshop/`](nuvemshop/): arquivos produtivos do tema clássico personalizado da loja.

Leia [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md) antes de iniciar alterações. Para trabalhar no tema, consulte também [`nuvemshop/README.md`](nuvemshop/README.md) e [`nuvemshop/HANDOFF_SULMINA.md`](nuvemshop/HANDOFF_SULMINA.md).

## Segurança

Configurações locais de conexão, credenciais e arquivos `.nuvem` não devem ser versionados. O `.gitignore` da raiz os exclui.
